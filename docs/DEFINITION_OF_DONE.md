# DEFINITION_OF_DONE.md

## 1. Feature Done

A feature is done only when:
- behavior meets PRD;
- UI matches DESIGN;
- content uses approved source;
- offline behavior works;
- state persists if required;
- relevant tests pass;
- no unrelated regression;
- docs updated if decision changed.

## 9. Not Done If

Not enough:
- desktop only;
- build only;
- simulator-only DnD claim;
- hardcoded score;
- content embedded in widgets;
- results vanish after restart;
- WebView wrapper;
- remote font/audio dependency.
